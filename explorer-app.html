Eddy covariance MRV for NBS projects

Biomass inventory and soil core MRV approaches face two fundamental problems: 1) high uncertainty and 2) failure to credit carbon outside sampled pools. Eddy covariance towers measure net carbon exchange continuously and directly, unlocking additional credits and increasing project returns.

In addition, eddy covariance provides continuous restoration monitoring for early-warning and comprehensive carbon cycling insights.

This dashboard explores profitability of NBS projects using eddy covariance MRV compared to soil core + biomass inventory approaches.

Modeling details & assumptions

Notation

  • T: project window, 10 years; A: project size (ha); p: credit price ($/t CO2e)
  • C: carbon stock change over the project window (t CO2e/ha) = annual rate × T
  • fabove, froots, fsoilC, flitter, fleak: fractions of C change in each pool by ecosystem
  • dshallow: share of belowground carbon (roots + soil) that is shallow, i.e. sampled by soil cores; fshallow = (froots + fsoilC)·dshallow; fdeep: the remaining (froots + fsoilC)(1 − dshallow) is deep and unsampled
  • ubio, usoil: uncertainty deductions of biomass plots and soil cores; a, b: EC uncertainty coefficients
  • CV: plot-to-plot coefficient of variation of biomass (heterogeneity slider); k: soil C change CV ÷ biomass CV; r: footprint factor; z: normal quantile for the confidence interval (1.645 at 90%)

Inventory (biomass plots and soil cores)

creditsinv = C · [ fabove(1 − ubio) + fshallow(1 − usoil) + [ flitter(1 − ulitter) if litter is counted ] ]  (t CO2e/ha)
costinv = nsurveys · nplots · ( ncores · ccore + cbiomass )

If “Soil coring in inventory” is switched off, only aboveground biomass is measured: shallow belowground carbon earns no credits and coring costs drop out.

Only aboveground carbon and shallow belowground carbon (roots + soil sampled by cores) are measured. Deep belowground carbon and leakage earn no credits. Litter earns credits only if “Count litter” is switched on (in the controls above); no extra cost is added for it.

Eddy covariance

uEC = √[ (a + b · C)² + (urep · C)² ]  (t CO2e/ha deducted)
creditsEC = max( C · (1 − fleak) − uEC, 0 )  (t CO2e/ha)
costEC = ( capex + opex · T ) · ( ntowers + nbaseline )

The tower sees net exchange of all pools, so deep soil and litter are included. Only leakage and the uncertainty deduction are removed.

The first term is FLUXNET measurement error; the second is how well the towers represent the whole project (below). nbaseline is fixed at 1.

Landscape heterogeneity: sample sizes and sampling uncertainty

Plot and tower counts meet ±10% at 90% confidence requirements.

nplots = max( 30, (z · CV / 0.10)² )    ubio = z · CV / √nplots    usoil = z · k · CV / √nplots
ntowers = max( 1, (z · r · CV / 0.10)² )    urep = z · r · CV / √ntowers

r < 1 because each tower footprint averages over tens of hectares.

Assumptions

  • The project window is 10 years.
  • EC tower uncertainty scales with net ecosystem exchange according to FLUXNET data (ρ = 0.09).
  • Spatial scaling via modeling or remote sensing is not incorporated.
  • One CV describes the whole project; strata (age classes, cover types) are not modeled separately. Real projects estimate CV from pilot plots or a remote-sensing proxy (e.g. lidar canopy height).
  • The footprint factor r = 0.2 is illustrative, inferred from paired-tower studies rather than reported by them.
  • z uses the normal distribution. With few samples (e.g. 1–3 towers) a t-value would be larger; raise the confidence interval to be more conservative.
  • Additional biomass surveys (e.g. lidar) not considered.
  • Not based on any specific protocols, as they can change rapidly; this serves as a scoping study.
